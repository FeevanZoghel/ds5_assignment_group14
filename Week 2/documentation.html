Code structureren: studentrecords

CSV inlezen, cijfers berekenen en een rapport maken

De oorspronkelijke code leest studentrecords uit een CSV-bestand. De code berekent het gemiddelde en toont alleen studenten met een cijfer van minstens 80. De opdracht is om deze lange code op te splitsen in kleinere, begrijpelijke functies.

Functie 1

read_records(file_path)

Leest het CSV-bestand en geeft een lijst met records terug.

Functie 2

calculate_average(records)

Berekent het gemiddelde cijfer van alle studenten.

Functie 3

filter_records(records, minimum)

Selecteert studenten die minimaal het opgegeven cijfer hebben.

Functie 4

print_report(records)

Print het gemiddelde en het studentrapport op een vaste manier.

def calculate_average(records: list[dict[str, str]]) -> float:
    """Bereken het gemiddelde cijfer. Author: Matthijs."""
    total = sum(float(record["Grade"]) for record in records)
    return total / len(records)
Belangrijk: voeg voor iedere functie een beschrijving van de input, output en verantwoordelijke persoon toe.
02

Mandelbrotvisualisatie

Een fractal berekenen als vierkante afbeelding

Voor ieder complex getal c wordt de reeks zn+1 = zn2 + c berekend. Als de absolute waarde groter wordt dan 2, is het getal divergent. Het aantal iteraties tot dat moment heet de diverging index.

Start met z0 = 0. Als |zn| > 2, geef n terug. Gebeurt dat niet binnen 100 iteraties, geef dan 0 terug.
Complexe getallen

complex_number(x, y)

Maakt het complexe getal x + yi.

Berekening

complex_limit(c)

Geeft de diverging index terug, of 0 als de reeks niet divergeert.

Data

create_mandel_data(width)

Maakt een width × width NumPy-array met indices.

Visualisatie

draw_mandel(width)

Toont de array als afbeelding met een kleurenschaal.

draw_mandel(200)
draw_mandel(300)
draw_mandel(500)
draw_mandel(800)

03

PageRank en het wereldwijde web

Populariteit schatten door een surfer te simuleren

PageRank schat hoe vaak iemand op een webpagina terechtkomt. De surfer volgt links vanaf de huidige pagina en bij een ongerichte graaf kan hij naar een verbonden node gaan. Door veel stappen te simuleren, wordt de verhouding van bezochte nodes een schatting van de PageRank.

3.1 Ongericht

Zelf een netwerk maken

Maak zonder graph generator een Barabási-Albert-netwerk. Nieuwe nodes kiezen bestaande nodes met een kans die afhangt van de degree.

3.2 Gericht

Links met pijlen

Gebruik nx.DiGraph voor Wikipedia-links. Een pagina kan alleen naar een bestaande uitgaande link surfen.

Analyse

Verdeling tonen

Visualiseer zowel het netwerk als de verdeling van de PageRank- waarschijnlijkheden met bijvoorbeeld een histogram.

P(page) = aantal bezoeken aan page / totaal aantal bezoeken

Belangrijke functies

  • calculate_probabilities(G): berekent selectiekansen op basis van degree.
  • create_network(k, N, M): bouwt het ongerichte netwerk op.
  • simulate_pagerank(G, steps): simuleert de surfer en telt bezoeken.
  • load_directed_network(file_path): leest bron- en doelartikelen uit de CSV.
  • visualize_network(G): tekent nodes en verbindingen.
  • plot_pagerank_distribution(scores): toont de verdeling van scores.
G = create_network(k=5, N=400, M=4)
scores = simulate_pagerank(G, steps=100_000)
plot_pagerank_distribution(scores)
